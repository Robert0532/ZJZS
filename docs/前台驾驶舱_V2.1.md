# 前台数据驾驶舱（V2.1）

> 入口：`/portal`（登录后访问，或从登录页「登录前台」进入）
> 后端：`PortalController` + `PortalService`，接口前缀 `/api`

## 1. 页面结构

```
/portal                        驾驶舱大厅
├─ 领导数据驾驶舱（通栏）        全公司汇总，视觉上单独一条
└─ 5 列 × 3 行 = 15 格           财务部 … 项目部，顺序与后台序号 1-15 一致
   └─ /portal/cockpit/{key}     舱内页（key 与后台一级菜单 path 相同）
```

卡片文案统一为「部门名 + 数据驾驶舱」，长度放不下的（如 `安全生产监督管理部数据驾驶舱` 13 个字）拆成两行：上行部门名、下行「数据驾驶舱」。

缩略图是纯 SVG 图表剪影（`components/PortalThumb.vue`），按卡片序号做种子生成固定形状，不依赖外部图片，也不受刷新影响。

## 2. 权限口径：全部可见可点，舱内过滤

| 环节 | 行为 |
|---|---|
| 大厅卡片 | **16 张全部返回给任何登录账号**，不按权限裁剪，保证宫格形态稳定 |
| 角标 | 不在数据范围内的卡片显示「受限」角标，仍然可以点击 |
| 舱内页 | 越权时不返回 403，而是 `accessible=false` + 原因 + 可去的舱（`peers`） |
| 数字 | 仅统计当前账号数据范围内的部门 |

`accessible` 由 `DataScopeHelper.visibleDeptIds()` 计算：

| `data_scope` | 可见部门 |
|---|---|
| 1 全部数据 / admin | `null`（不限部门，16 张全部可用） |
| 2 自定义部门 | `sys_role_dept` 里的部门 |
| 3 本部门 | 仅本部门 |
| 4 本部门及以下 | 本部门 + `ancestors` 命中的子孙 |
| 5 仅本人 | 部门维度同本部门（个人维度由业务查询的 `owner_id` 收窄） |

多角色取最宽口径。上下文中拿不到登录态时**失败关闭**（抛异常），不会退化成"查全部"。

## 3. 接口

### `GET /api/portal/overview`

```json
{
  "code": 200,
  "data": {
    "scopeLabel": "本部门",
    "cards": [
      {
        "key": "finance",
        "title": "财务部数据驾驶舱",
        "deptName": "财务部",
        "deptId": 3,
        "subtitle": "部门数据填报与汇总",
        "leader": false,
        "accessible": true,
        "restrictedHint": null
      }
    ]
  }
}
```

### `GET /api/portal/cockpit/{key}`

```json
{
  "code": 200,
  "data": {
    "key": "legal",
    "title": "商务法务部数据驾驶舱",
    "deptName": "商务法务部",
    "deptId": 4,
    "leader": false,
    "accessible": false,
    "message": "当前账号的数据范围为「本部门」，无权查看「商务法务部」的数据",
    "scopeLabel": "本部门",
    "userCount": null,
    "visibleDeptCount": 1,
    "visibleDepts": ["财务部"],
    "peers": [{ "key": "finance", "title": "财务部数据驾驶舱", "accessible": true }]
  }
}
```

> 两个接口都**不挂 `@RequiresPerm`**：登录即可访问，越权由 Service 层按 `data_scope` 过滤。

## 4. 扩展一个新部门

1. `sys_dept` 加部门（或用后台「部门管理」新增）
2. `PortalService.MODULES` 加一行 `new ModuleDef("<key>", "<部门名>", false)`，`key` 建议与后台一级菜单 `path` 一致
3. 后台菜单里给该部门建「数据填报 / 数据驾驶舱」，权限标识沿用 `{key}:report:*`、`{key}:cockpit:view`

## 5. 尚未接入

舱内 KPI 目前只有结构性数字（本部门账号数、可见部门数），**业务指标（填报进度、审核通过率、趋势图）等业务表落地后再接**，页面已预留「数据视图」区块。
